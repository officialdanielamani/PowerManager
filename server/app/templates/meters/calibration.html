Zero: the sensor's offset with no load. Disconnect the load, run the check, then set it: the meter subtracts it from every reading (current, power, energy, limits, history).

Tare: a load that is connected and should count as 0 (a charger, a fixture). Connect it, run the check, then set it: values are shown without it, and the meter's limits use the tared values (Configuration → Use tared values for limits).
